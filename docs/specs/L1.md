# L1 - High-Level Requirements

The user approved this scope on 2026-09-07. The product brief is
[../prompt.md](../prompt.md); repository constraints are in
[../../AGENTS.md](../../AGENTS.md). Detailed, testable behaviors and explicitly
chosen first-version defaults are in [L2.md](L2.md).

## L1-001: My Work

Users must be able to upload their photographs, record intent and feedback
preferences, revisit saved critiques, add notes, and compare later attempts.

## L1-002: Actionable AI critique

Critiques must explain strengths, technical observations, composition, three
priority improvements, and a practice exercise. Feedback must respect intent,
cite visible evidence, acknowledge uncertainty, and avoid invented shooting
details.

## L1-003: Inspiration library

Users must be able to save reference images through uploads or source URLs,
preserving available previews, source links, attribution, and personal notes
separately from their own work. Restricted or unsuccessful imports must support
manual fallback.

## L1-004: Editable AI metadata

Users must be able to review and edit AI-generated descriptions and visual tags,
with suggestions clearly distinguished from personal notes.

## L1-005: Boards

Users must be able to create, rename, and delete boards and organize a reference
into multiple boards without duplicating it.

## L1-006: Photographer bookmarks

Users must be able to save and edit photographer portfolio bookmarks, associate
references with photographers, and obtain suggested summaries grounded in
accessible content.

## L1-007: Search and discovery

Users must be able to find references and photographer bookmarks using keywords,
semantic queries, and combined tag, board, and item-type filters, and discover
related references.

## L1-008: Persistence and deletion

Saved content must persist across sessions. Users must be able to edit and delete
it, with deletion removing associated files and search records while preserving
unrelated content.

## L1-009: Reliable AI processing

Slow AI operations must run asynchronously with visible progress, recoverable
failures, retries, and reuse of completed work where applicable. Production AI
uses real providers only. Historical sample critiques are archived separately
from current critiques and comparisons without deleting photographs or notes.

## L1-010: Security and privacy

The platform must store local user accounts, issue authentication tokens in the
Loupe backend, and enforce authorization for private content,
validate uploads and external URLs, protect stored data and provider credentials,
and keep personal work and critiques private by default.

## L1-011: Accessible, responsive experience

My Work, Inspiration, Photographers, Search, and Locations must provide an
accessible, image-first experience across mobile through desktop sizes, including
clear empty, loading, processing, and error states. (Updated 2026-09-12: Locations
added.)

## L1-012: Performance and operations

The platform must meet defined, measurable responsiveness and processing targets,
support recovery from failures, and provide operational diagnostics and setup
guidance.

## L1-013: Independent design system

A separately buildable and deployable design-system site must document the
authoritative visual tokens and reusable component states used by the
application.

## L1-014: Location library

Users must be able to save scouted locations with a name, address, optional
coordinates, a bounded set of images, setting, personal notes, and tags; browse
them image-first; and edit or delete them, kept separate from My Work and the
inspiration library. (Added 2026-09-12.)

## L1-015: AI location scouting report

Each location must support an explicitly requested AI scouting report grounded in
its images: suitability for defined shoot types, recommended times of day,
applicable composition techniques, the group size the location accommodates, and
cautions, each with reasons tied to visible evidence and stated uncertainty.
Reports must be labeled AI-generated, never assert non-visible logistics, and
never overwrite user notes. (Added 2026-09-12.)

## L1-016: Shoot planning search

Users must be able to describe a shoot idea in natural language and structured
filters and receive ranked owned locations showing each location's suggested
time of day, suitability, and group-size fit, and find locations by keyword over
their saved details. (Added 2026-09-12.)

## First-version exclusions

Social feeds, public profiles, public sharing, payments, complex team features,
full-site crawling, progress tracking, and personalized learning plans are
outside this scope. Comparing two saved attempts and providing a practice
exercise remain in scope. The standalone design-system site contains synthetic
examples and no personal library content. For Locations, geocoding, maps,
distance or proximity filters, sun-position or weather calculation, permit or
booking information lookup, and sharing locations are outside this scope; a
location's address and coordinates are entered manually and stay private.
